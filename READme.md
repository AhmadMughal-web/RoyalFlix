## 🎬 What is RoyalFlix?

</div>

**RoyalFlix** is a full-stack, production-grade movie streaming platform I am actively building from scratch. The goal is simple — create a streaming experience that **beats Netflix in UI, speed, and features**. This is not a tutorial follow-along. Every line of code is written by me, every design decision is mine, and every feature is planned with real users in mind.

This project is currently **in active development** and is part of my portfolio to showcase my ability to build **real-world, scalable web applications** — not just CRUD apps.

## 🛠️ Tech Stack

</div>

<div align="center">

| Layer        | Technology                        | Why I Chose It                           |
| ------------ | --------------------------------- | ---------------------------------------- |
| ⚛️ Frontend   | React 18 + Vite                   | Blazing fast HMR, modern React features  |
| 🎨 Styling    | Pure CSS + Custom Design System   | Full control, no UI library limitations  |
| 🔀 Routing    | React Router DOM v6               | Industry standard, clean nested routes   |
| 🌐 API Layer  | Axios + TMDb API                  | Real movie data, 1M+ titles              |
| 🔐 Auth       | JWT + Google OAuth 2.0            | Secure, industry-standard authentication |
| 🖥️ Backend    | Node.js + Express.js              | Fast, scalable REST API                  |
| 🗄️ Database   | MongoDB + Mongoose                | Flexible schema for complex media data   |
| 🔒 Security   | Helmet + Rate Limiting + bcryptjs | Production-grade security                |
| 🚀 Deployment | Vercel + Railway (Planned)        | CI/CD pipeline, auto-deploy              |

## ✅ Features — Completed

</div>

### 🎨 UI & Design
- 🖤 **Premium Black & Cyan Design System** — Custom built, zero UI libraries
- 📱 **Fully Responsive** — Mobile, Tablet, Desktop — pixel perfect on all screens
- ✨ **Smooth Animations** — Page transitions, hover effects, skeleton loaders
- 🎠 **Auto-Sliding Hero Section** — Real movie backdrops from TMDb with cinematic overlay
- 🃏 **Interactive Movie Cards** — Hover reveal with play button, rating, and watchlist toggle
- 🔝 **Sticky Smart Navbar** — Transparent on top, solid on scroll with blur effect

### 🎬 Content & Discovery
- 🔥 **Trending Now Row** — Real-time trending from TMDb
- 🆕 **New Releases Row** — Latest movies in theaters
- 🏆 **Top Rated Row** — All-time best movies with rank numbers
- 📺 **TV Shows Section** — Popular and top rated series
- ⚔️ **Anime Section** — Japanese anime with genre filters
- 🇮🇳 **Bollywood Section** — Hindi language movies separate section
- 🎭 **Genre Filtering** — Action, Romance, Comedy, Horror, Thriller, Sci-Fi, Drama and more
- 🌍 **Origin Filtering** — Hollywood, Bollywood, Turkish Drama, K-Drama
- 🔍 **Live Search** — Multi-search across movies, TV shows and anime simultaneously

### 🔐 Authentication
- 📧 **Email + Password Registration & Login**
- 🔑 **JWT Token Authentication** — Secure, stateless, 7-day expiry
- 🟢 **Google OAuth 2.0** — One-click Google sign in
- 🛡️ **Protected Routes** — Unauthorized users redirected to login
- 👤 **User Profiles** — Name, avatar, plan status

### 📋 User Features
- ➕ **Watchlist** — Add/remove movies and shows, persisted in MongoDB
- 📜 **Watch History** — Track what you've watched (backend ready)
- ▶️ **Video Player** — Full-screen player with custom top controls
- 🌐 **Audio Language Toggle** — English / Hindi dubbed switcher in player
- ℹ️ **Movie Detail Pages** — Full info, cast, ratings, trailer, similar movies
- 📺 **TV Detail Pages** — Season tabs, episode counts, cast

### 🖥️ Backend API
- 🔒 **Secure REST API** — Helmet, CORS, Rate Limiting (100 req/15min)
- 📦 **MongoDB Integration** — Users, watchlist, watch history
- 🎬 **TMDb Proxy Routes** — Server-side API calls
- 📝 **Morgan Logging** — Full request logging in development
- ⚠️ **Global Error Handler** — Consistent error responses

## 🚀 Run Locally

</div>

```bash
# 1. Clone the repository
git clone https://github.com/yourusername/royalflix.git
cd royalflix

# 2. Setup Frontend
cd frontend
npm install
cp .env.example .env
# Add your keys in .env
npm run dev
# Runs on http://localhost:3000

# 3. Setup Backend (new terminal)
cd backend
npm install
cp .env.example .env
# Add your keys in .env
npm run dev
# Runs on http://localhost:5000
```

**Frontend `.env`**
```env
VITE_TMDB_API_KEY=your_tmdb_api_key
VITE_TMDB_BASE_URL=https://api.themoviedb.org/3
VITE_TMDB_IMAGE_URL=https://image.tmdb.org/t/p
VITE_BACKEND_URL=http://localhost:5000/api
VITE_GOOGLE_CLIENT_ID=your_google_client_id
```

**Backend `.env`**
```env
PORT=5000
MONGO_URI=mongodb://localhost:27017/royalflix
JWT_SECRET=your_secret_key
JWT_EXPIRES_IN=7d
GOOGLE_CLIENT_ID=your_google_client_id
TMDB_API_KEY=your_tmdb_api_key
CLIENT_URL=http://localhost:3000
```

## 🔌 API Endpoints

</div>

```
🔐 AUTH
POST   /api/auth/register        Register new user
POST   /api/auth/login           Login with email/password
POST   /api/auth/google          Google OAuth login
GET    /api/auth/me              Get current user

👤 USER (Protected)
GET    /api/user/watchlist       Get user watchlist
POST   /api/user/watchlist       Add to watchlist
DELETE /api/user/watchlist/:id   Remove from watchlist
GET    /api/user/history         Get watch history
POST   /api/user/history         Update watch history
PUT    /api/user/profile         Update profile

🎬 MOVIES
GET    /api/movies/trending      Trending content
GET    /api/movies/popular       Popular movies
GET    /api/movies/search?q=     Search content
GET    /api/movies/:id           Movie details
```
